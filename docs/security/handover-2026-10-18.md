## 12. GUI 与内核解耦（2026-10-31，待发版）

**动机**：GUI 原先静态链接整颗内核（`exvlan` crate），导致 ①每次 GUI 构建都要重编内核（macOS 31 min / Windows 38 min）②内核无法独立升级。

**结果**：`exvlan-studio` 依赖 crate 数 **573 → 440**，内核 crate 与 `tun-easytier`/`smoltcp`/`quinn`/`tokio-websockets`/`kcp` 全部移出依赖树；CI 实测 **macOS 22.2 min / Windows 23.0 min**（−29% / −40%）。内核改为独立二进制 + root 守护进程。

### 架构

| 层 | 变化 |
|---|---|
| `exvlan/rpc`（新 crate） | GUI 侧轻量层：`service_manager`、日志栈（`log` + `tracing_rolling_appender`）、桌面 RPC 拨号器（`TokioTcpSocket` + `GuiHostRuntime`，不依赖内核 crate） |
| 桌面 GUI | 只依赖 `exvlan-core(management)` + `exvlan-proto` + `exvlan-rpc`；**永不 root** |
| 移动端 | 保持内核库 + 进程内实例（cfg 门控），`exvlan` 仅 android/ios 依赖 |
| 内核 | 独立二进制，落盘 root-owned 目录（见下） |

### 内核落盘与安装

```
macOS   /Library/Application Support/exvlan/core/exvlan
Windows C:\ProgramData\exvlan\core\exvlan.exe
Linux   /opt/exvlan/core/exvlan
```
- 同目录 `version`、`service.fingerprint`（服务程序+参数指纹，用于避免每次启动提权）
- 安装流程：复制 `.new` → **预演执行 `--version` 校验** → 原子 rename → 写版本 → 收紧权限；失败不影响现有内核
- 提权收敛到 4 个内部子命令：`--install-kernel` / `--install-service` / `--uninstall-service` / `--service-ctl`
- 指纹一致时 `ensure_kernel_service` 直接返回 `current`，**零提权**

### 分发与升级

- 端点：`https://dl.exvlan.era-x.cn/core/`（**可配置**，`EXVLAN_KERNEL_BASE_URL` 优先）
- `manifest.json`：`{schema, latest, versions[{version, rpc_schema, min_studio_version, assets{platform:{file,sha256,entry}}}]}`
- `sha256` 针对**内核 zip 本体**；解压后再取 `entry` 安装
- 回滚：不保留 `exvlan.prev`，通过 manifest 历史版本列表**重新下载安装**；镜像合并最近 KEEP 个 release 的 `versions[]`
- 升级体验：启动静默检查 + 24h 节流 → 红点 → 用户确认 → 下载 + 一次密码

### CI 链路

```
core.yml   → artifacts/kernel.json（version/platform/entry）
           → core-<platform> artifact（**不重编**，studio 直接复用）
studio.yml → download-artifact → resources/kernel/exvlan[.exe] → 打包
release.yml→ 汇总 kernel.json + 计算 zip sha256 → manifest.json（缺文件则发版失败）
```

### 关键坑（务必记住）

1. **feature 泄漏**：`exvlan-rpc` 曾写死 `exvlan-core = { features = ["management"] }`，Cargo feature 统一后污染内核的 `--each-feature` 构建（`web-client` 组合下 `WebClient::new` 参数数量不符）。**子 crate 不要替别人决定 feature**。
2. **TUN 必须 root**：`normal` 模式改为「连接 root 守护进程 + 退出时停实例」，而不是「非特权 sidecar」（后者建不了 TUN）。
3. **Windows runner 抖动**：`taiki-e/install-action` 偶发 bash 启动失败（partner-runner-images#169）；`wasm-pack` 已门控为仅非 Windows。
4. **上游同步冲突**：`lib.rs` 属上游文件但改动较大；新增逻辑尽量放新 crate（`exvlan/rpc`、`kernel.rs`、`kernel_update.rs`）。

### 待办

- 内核 RPC **无鉴权**（仅绑 `127.0.0.1`）：本机任意用户可控制 root daemon，已记录为后续安全项（Unix socket + 0600 或 token）。
- 移动端预编译内核库复用（P6）：iOS 受 App Store 限制**不可**运行时下载内核；两端均不做热更新。
