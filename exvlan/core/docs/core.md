# 核心模块

## 模块概述

核心模块是 exvlan 的基础，提供了程序的主要入口点和核心功能，包括命令行解析、内存分析、启动管理等。该模块是整个系统的控制中心，负责协调各个子模块的工作。

## 目录结构

```
exvlan/core/src/
├── lib.rs              # 核心库入口
├── core.rs             # 核心功能实现
├── main.rs             # 主入口
├── cli.rs              # 命令行界面
├── launcher.rs         # 启动器
└── utils.rs            # 工具函数
```

## 主要组件

### 核心库入口 (lib.rs)

**功能**：核心库的入口点，导出主要模块和功能

**主要导出**：
- 各个子模块的导出
- `ShellType` 枚举：定义不同类型的命令行 shell
- 命令补全生成函数

### 核心功能实现 (core.rs)

**功能**：实现核心功能，包括内存分析、CLI解析、网络选项配置等

**主要组件**：
- **内存分析**：提供内存使用情况的监控和分析
- **CLI 结构体**：定义命令行参数和选项
- **网络选项**：配置网络相关的选项
- **日志选项**：配置日志相关的选项
- **RPC 门户选项**：配置 RPC 门户相关的选项
- **Windows 服务**：Windows 服务相关的功能

### 主入口 (main.rs)

**功能**：程序的主入口点，负责启动和初始化系统

**主要功能**：
- 解析命令行参数
- 初始化全局上下文
- 启动主服务
- 处理错误和异常

### 命令行界面 (cli.rs)

**功能**：实现命令行界面，处理命令行参数和选项

**主要功能**：
- 定义命令行参数和选项
- 解析命令行输入
- 提供命令帮助信息
- 生成命令补全

### 启动器 (launcher.rs)

**功能**：负责启动和管理网络实例

**主要功能**：
- 启动网络实例
- 管理实例的生命周期
- 处理实例的启动和停止

### 工具函数 (utils.rs)

**功能**：提供通用的工具函数

**主要功能**：
- 各种辅助函数
- 通用的工具方法

## 核心功能

### 内存分析

核心模块提供了内存使用情况的监控和分析功能，帮助开发者了解系统的内存使用情况，及时发现和解决内存问题。

### 命令行解析

核心模块实现了完整的命令行解析功能，支持各种命令和选项，提供了友好的命令行界面。

### 网络配置

核心模块提供了网络相关的配置选项，包括 IP 地址、子网、DNS 设置等，方便用户根据需要配置网络。

### 日志管理

核心模块提供了日志相关的配置选项，支持不同级别的日志输出，帮助开发者和用户了解系统的运行状态。

### Windows 服务集成

核心模块支持 Windows 服务集成，可以作为 Windows 服务运行，提供更好的系统集成。

## 接口说明

### 主要函数

#### [parse_cli](../src/core.rs#L1212-L1222)

**功能**：解析命令行参数

**参数**：无

**返回值**：`Cli` - 解析后的 CLI 配置对象

#### [run_main](../src/core.rs#L1263-L1416)

**功能**：运行主服务

**参数**：
- `cli: Cli`：CLI 配置对象

**返回值**：`anyhow::Result<()>` - 运行结果，成功返回 `Ok(())`，失败返回错误

#### [memory_monitor](../src/core.rs#L1417-L1460)

**功能**：监控内存使用情况

**参数**：
- `_force_dump: Arc<AtomicBool>`：强制导出内存分析结果的原子布尔值

**返回值**：无

#### [main](../src/core.rs#L1461-L1533)

**功能**：程序主入口

**参数**：无

**返回值**：`ExitCode` - 程序退出码

#### [validate_config](../src/core.rs#L1534-L1542)

**功能**：验证配置

**参数**：
- `cli: &Cli`：CLI 配置对象的引用

**返回值**：`anyhow::Result<()>` - 验证结果，成功返回 `Ok(())`，失败返回错误

## 使用示例

### 基本使用

```rust
// 导入核心模块
use exvlan_core::core::parse_cli;

// 解析命令行参数
let cli = parse_cli();

// 运行主服务
run_main(cli).await?;
```

### 内存分析

```rust
// 启用内存分析
let profiler = set_prof_active(true);

// 执行操作
// ...

// 导出内存分析结果
dump_profile(Some("memory_profile"));
```

### 命令行使用

```bash
# 创建网络实例
exvlan create --name my-network --ipv4 10.0.0.1/24

# 启动实例
exvlan start --name my-network

# 停止实例
exvlan stop --name my-network

# 列出实例
exvlan list
```

## 注意事项

1. **内存使用**：核心模块使用了内存分析功能，可能会增加一定的内存开销，在生产环境中可以禁用。

2. **命令行参数**：使用命令行参数时，需要确保参数的正确性，避免因参数错误导致程序异常。

3. **网络配置**：网络配置需要根据实际网络环境进行调整，确保配置的正确性。

4. **Windows 服务**：在 Windows 系统上，作为服务运行时需要确保服务权限正确。

5. **日志配置**：日志级别需要根据实际需要进行配置，避免日志过多或过少。
